# Worldapocalyptic Retro Game

Retro post-apocalyptic 2.5D game: Three.js (render) + Anime.js v4 (tweens/FX/UI) + Planck.js (2D physics/ragdolls).

Before writing game code, use the project skill `apocalypse-25d-game-dev`
(`.claude/skills/apocalypse-25d-game-dev/SKILL.md`). Anime.js is v4: no `anime()` default export.
